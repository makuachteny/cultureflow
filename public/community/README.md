# Community photos

Drop South Sudanese / diaspora event photos here, then update
`src/lib/stock-photos.ts` to point at them (e.g. `/community/wedding.jpg`).

Naming convention:
  - cultural-1.jpg, cultural-2.jpg, ...
  - wedding-1.jpg
  - faith-1.jpg
  - music-1.jpg
  - community-1.jpg
  - business-1.jpg
  - family-1.jpg

Recommended size: 1600 × 900 (or 16:9). JPG quality ~75. Aim for <300 KB each.
