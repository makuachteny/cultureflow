# Docs

Design references and product strategy that aren't shipped with the app
but are useful for context. None of these files are imported by code; they
live here for humans.

- `strategic-blueprint.docx` — original product brief for the South Sudan
  events platform that became CultureFlow.
- `design-references/` — non-code reference material kept alongside the
  repo for context. Currently holds `savanna-sunset-source.pdf`, the
  source for `/public/savanna-sunset.jpg`. Not shipped, not imported by
  code.
